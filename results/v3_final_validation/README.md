# V3 Final Validation

This prospective program complements the completed controlled research repair.
The program is complete. The input freeze was sealed before the first and only
formal forward. Controlled and natural 5,000-draw statistics and saved-output
acceptance passed; the run ledger contains no confirmation corrections.

Protocol: [V3 protocol](../../reviews/v3_protocol.md).
Machine-readable progress: [STATUS.json](STATUS.json).

Original images, features, models, predictions, repair artifacts, operational
gates and unrecoverable M3 evidence are preserved. New independent confirmation
depends on a verified exposure audit and a content-bound code/model/cohort freeze.
An unobserved source split is a candidate for confirmation, not proof of independence.

Subdirectories are owned by separate execution agents: `exposure/`,
`replication/`, and `pipeline/`. The parent coordinates integration, records
the formal freeze, verifies old input hashes and runs final acceptance.
Images, feature caches and large public encoder/detector weights remain local.
Published evidence includes lossless prediction gzip, raw score traces, formal
bootstrap arrays, fitted small-model archives and a byte-identical proposal
geometry bank. Saved-result verification and full forward reconstruction are
different capabilities; see [replay instructions](../../docs/v3_reproduction.md).
