## 写正文前的优先修正

- **数学解释**：E-AURC/RER并非完全accuracy-independent；logits温度不保证MSP跨样本排序不变。
- **统计汇总**：多个阶段直接平均三seed CI端点，不是seed-mean估计量的标准95% bootstrap CI。
- **机制表述**：小D_label来自两条路径的正负抵消，不能称错误转移不重要；展示四角与交互。
- **信息归因**：E1b混用alternate-scoring与candidate–candidate特征，未独立证明交互增量。
- **文档事实**：统一最终RQ、V2训练状态、预冻结证据等级、公开结果索引与真实引用。

## 建议的论文主线

受控、目标在场的候选扩张改变预测正确性及其与置信度的关系；冻结嵌入衍生特征提供有限且依赖候选组成的额外可靠性信号。现有方法未稳定修复变化，统计分解还不能识别因果机制。
