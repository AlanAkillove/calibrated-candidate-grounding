## 必须修正的三个遗漏

### 1. [P2] “有限样本 E-AURC 必然非负”仍然错误

位置：`src/ccg/metrics/selective.py:175`。修补后的 docstring 仍写 `E-AURC >= 0`。当前数值定义把有限样本风险曲线的梯形积分，减去连续总体 oracle 公式；两者并非同一个离散积分定义，因此非负性并不普遍成立。

明确反例：confidence=`[0.8, 0.3]`、correctness=`[1, 0]`，排序已经是 oracle。当前实现得到 AURC=0.125，连续 oracle=0.15342640972002736，E-AURC=−0.028426409720027357。

这不是浮点误差，也不是错误排序。正文和代码应明确：保留既有数值定义，连续 oracle 是参考项；有限样本数值可能为负。不能通过截断为零来掩盖定义差异，也不能拿该有限样本非负性作为测试不变量。应补一个有意义的有限样本反例测试。

本次主表 E-AURC 及其配对变化不因此作废；它们使用同一定义，且完整存储算术已验证。不过“所有数学解释已纠正”的完成表述尚不成立。

### 2. [P2] 单独请求风险指标时，共同指标工具会报错

位置：`src/ccg/repairs/statistics.py:155–163`。`base_risk` 只在请求相应 RER 的分支里赋值，后面的 RER 处理却在分支外执行。

最小复现：

```python
metric_bundle([0.8, 0.3], [1, 0], metrics=("risk_at_50",))
```

实际为 `UnboundLocalError`，应返回 `{"risk_at_50": 0.0}`。这暴露的是本轮新增公共统计入口的指标组合边界，不需要扩展为一般代码审计。

应让 RER 的分母处理完整留在 RER 请求分支内，并补风险单项与风险/RER 组合的测试；全对样本上的风险仍然有定义，不能被 RER 的零分母策略牵连。当前正式 runner 的指标组合避开了此错误，已有正式估计复核通过，故不要求因此重训或重算所有结果。修正后需要绑定新源文件重新验收。

### 3. [P2] 21,026 的统计单位被写错

位置：`scripts/build_repair_report.py:240`、`:242`、`:730` 及其生成的候选说明、结果摘要和完成报告。

实际 CSV 是 10,425 条 RPN expression 记录加 10,601 条 DETR expression 记录。同一 sentence 可跨 family 出现。21,026 条记录仅包含 **10,607 个不同 sentence_id**。138 是 family-expression 级错配数，涉及 47 个 family-target-object 配对。

应写“在 21,026 条表达式–family 审计记录中发现 138 条错配”，同时保留 RPN 86/10,425、DETR 52/10,601 的分层结果。不能将它称为 21,026 个不同表达式，也不能由重复表达式数量暗示独立物体或独立样本数量。

源表本身没有错。现有 image-cluster bootstrap 也没有把这些重复表达式当独立 image 抽样。因此主要问题是生成器及文字单位，不是要求丢弃重复表达式或重新计算主 CI。应修改生成器，再生成当前说明，避免手工改表后下次渲染恢复错误。

## 主要修补是否真正落实

### A：统计、指标和温度

公共 bootstrap 实现为每次共同抽取 image cluster，在每个固定 seed 内先形成效应，再平均。这是固定三个模型效应的平均，不是 ensemble；relative、DoD 与宏平均在同次抽样内形成。所有已存抽样均值/区间通过检查，无效抽样保持 NaN 并单列有效数量。旧 gate 没有追改阈值，M3 未被塞入近似 CI。

温度跨样本 MSP 排序反例成立；当前文本已删除“统一 logits 温度必然保序”的论证，也没有继续用温度漂移很小来排除尺度因素。E-AURC/RER 的 accuracy 依赖已纠正，但有限样本 oracle 边界遗漏如上。

主结果可以保留：合并 testA/testB，B3 MSP 的 K5→K50 AUROC 从约 0.84072 降到 0.78902；温度源对应的配对 gap 约 0.05170，95% CI [0.03983, 0.06355]。应注明精度/预测来源，不拼接不同 archive 的尾数。不能把选择性指标恶化单独称作 discrimination 下降。

### B：信息来源与 ID/OOD

四组特征固定，训练和选型仅用原 train/tune 图像；大 K/小 K 的训练行数相同。模型、配置、曲线和逐表达式预测已保存。原 logK 标准化确有可复现错误，修补后重新训练了相关 ScoreDeepSets 设置。不能继续用旧模型拟合失败支持“分数中没有信息”。

新实验提供明确的条件性结果，不能只用“并非普遍有效”笼统带过：

| 合并测试的 Full−(S+Q) AUROC | 点估计 | 95% 配对 CI |
|---|---|---|
| random K5 | 0.000679 | [−0.001656, 0.002922] |
| random K50 | 0.013638 | [0.011202, 0.016070] |
| matched hard K5 | 0.027089 | [0.024338, 0.029744] |
| dose m0，K10 | 0.001379 | [−0.001006, 0.003688] |
| dose m8，K10 | 0.025464 | [0.022670, 0.028348] |

random K10/20 与 dose m2/4 也有正向区间。K5、m0 跨零并不说明其他条件的增益不存在；正向区间也不识别候选交互的因果机制。描述为“冻结 candidate–candidate 衍生特征在较大/特定组成候选集上，提供 query–crop 特征之外的额外正确性判别信号”更准确。

ScoreDeepSets 在 K50 上 small-K 训练 AUROC≈0.67877，large-K 训练≈0.76003；同 K 配对增益≈0.08126，CI [0.07347, 0.08899]。Stats Logistic 对应增益≈0.00415，CI [0.00238, 0.00588]。这支持模型/训练分布敏感性，但不能把增益全部因果归于 K：训练标签比例、分数分布等也同时改变。两种 ScoreDeepSets 设置仍没有充分证明逼近了“最优分数函数”。128 行拟合诊断只检验有限配置，不能证明优化困难被彻底排除。

### C：候选与机制

错配确实存在；版本化 true-target-category 候选、固定模型前向及正式配对敏感性已完成。保留了不同历史来源的 cohort，而不是混用更大供给 cohort。交集和样本流失有记录；几何/objectness/IoU/重复及 distinct annotated-object 数均已落盘。

候选条数不能称独立竞争物体数量。举例，历史 RPN hard5 平均仅匹配约 3.14 个 distinct GT objects；hard10 约 4.53 个。整体 sensitivity 的小变化也不能证明错配表达式个体无影响，交集条件及流失对象仍限制外推。

四角、两条路径与交互已经补齐。DETR 的两条 label 切换效应约 −0.14155 和 +0.12922，interaction≈0.27077，CI [0.24120, 0.30235]；小净 label 分量来自明显抵消。三个 family 都存在相反路径方向。当前表述没有再把该统计恒等式等同于因果机制，也区分了 H1c accuracy harm 与 AUROC gap。

## 允许保留的限制及不能写成成功的部分

1. **M3 仍是历史结果不可精确重放。** 三个 backbone × 三个 seed 有真实恢复尝试、未通过的点指标和未发现可重放 checkpoint 的记录。这足以拒绝拿近似恢复替代旧模型产生新 CI，不应将它改写成“原方法结论被否定”。要区分原 frozen-store 的 1e-9、rescore 的 1e-4 与本轮对 committed M3 point 的 1e-9 精确重放检查；本轮 recovery 中逐 point 使用的阈值并不自动成为原协议对此 point 曾规定的阈值。相关失败记录/文字应继续明确检查对象和阈值来源。
2. **早期 A 批次缺少启动源快照。** 事后读取源哈希不能补造启动记录。当前数组一致性与本次直接重建的主结果支持数值有效性，但不补齐所有历史执行的来源链。若以后宣称每个修正版表都具备完整 source-to-table 重放记录，应只重跑该缺记录统计批次并在启动前保存 source snapshot，无需据此重训 B/C。
3. **全部新 raw archive 的更新前 SHA 快照不完整。** 目前可证明当前数组与摘要一致，不能证明所有修补数组在某次 metadata 派生前后逐字节未变。执行报告已保留这一限制，接受其诚实披露；不接受扩大为不存在的全量 before/after 实证。
4. **修补是结果驱动补充。** 固定三个训练模型下的测试采样区间不是训练随机性全貌，也不是未观察测试集上的独立确认。GT-assisted、target-present、最大 K 可行性 cohort 与 COCO 视觉域限制不能藏到最后一句。
5. **ECE 的 percentile 区间需要限制解释。** adaptive binning、绝对误差及接近零校准误差带来偏差/非光滑性；K5 的 ECE 点低于其 percentile 区间不是数据自相矛盾，但“计算出 2.5/97.5 分位数”不自动保证名义覆盖率。当前已存区间保留并标明方法，不能仅凭其正下界证明总体存在显著 miscalibration。

## 论文组织验收

当前论文蓝图已按问题依赖组织，符合避免实验流水账的方向。但它仍是蓝图，不是已经完成的优秀论文。正文应保留一条明确的证据主线：

**受控候选扩张下的可靠性变化 → 分数模型的训练/外推对照 → 条件性的额外特征信号 → 路径抵消与解释边界。**

其中最值得突出的新增证据是“V 在 hard/high-dose 条件下超越 S+Q”，而不只是“旧模型失败”。候选真实性/重复程度的审计紧贴 hard/dose 命题；ID/OOD 紧贴分数模型结论；跨 backbone、proposal、语言/外部验证分别嵌入它们检验的命题。历史 gate、阶段编号、试错时间线和完整负路线放附录。

不需要把 59 个 job、6,646 个主统计估计或全部候选敏感性行写进正文。每个主图回答一个命题：可靠性变化、ID/OOD 对照与特征来源、四角路径与交互。校准、选择性和判别三个对象分别解释；统计上的增量特征信号不要包装为机制识别或架构创新。

已查看 `figure_information_sources.png` 和 `figure_mechanism_paths.png`：增量的条件差异及路径抵消已经能直观看到，图中区间/方向与表一致。写论文时应把 `matched_same4/expb_m8` 等内部实验代号换成可自解释的条件名称，并在图注定义 S/Q/V、r/p、m 是 proposal 条数及每个 family 的 cohort；不能用同尺度面板暗示 family 间已做同 cohort 的因果比较。
