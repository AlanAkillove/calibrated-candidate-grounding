# V4 论文组织：从现象到有条件的可用信号

题目建议：《候选集合变化下视觉定位的正确性可靠性及其适用边界》。保持实证研究定位，不使用“通用退化机制”“因果结构贡献”或“新可靠性架构”作为题目。

全文中心问题是：候选改变之后，定位错误如何变化；可靠性评分能利用什么信号排序这些错误；这种改善在多大范围内可用？研究路线应按论证依赖组织，不按 Phase/V1/V2/V3/V4 时间顺序组织。

V4 新结论必须等正式结果与验收，见 `reviews/v4_scientific_review.md` 和 `results/v4_targeted_strengthening/publication/`。V3 的首次确认身份保持原记录；V4 对同一 FineCops 集的重新分析明示为结果驱动补充，不包装成第二次独立确认。

## 1. 问题：三种可靠性性质为什么要分开

引言用同一图像/表达的候选扩张引出 Accuracy、correctness AUROC 和选择性风险。受控目标在场时，加入错误竞争候选可使准确率下降，但这不必导致正误判别 AUROC 同步下降；自然集合扩张还提高目标召回。用这一张力提出问题，避免“候选越多置信度越坏，所以提出修复”的预设成功故事。

文献围绕视觉定位的候选接口、置信判别/拒绝、候选上下文分别组织。已有 grounding confidence、Ref-NMS、关系建模工作阻止声称首次提出可靠性或候选交互。我们的定位是明确条件下的比较、复制与边界，不以矩阵空白证明优先权。

## 2. 设计：评估条件、训练对象和推断对象

一个计算接口图画出原生RPN→controlled/natural→冻结scorer→可靠性评分。GT进入受控候选构造与事后正确性标签，不进入自然排序或V_pure函数。图区分 S/Q/旧V与新纯集合块的依赖；不将这个数据流图当因果图。

一张表列 proposal、CLIP、grounding head、温度、可靠性模型各自是否训练及冻结位置。B/16连同对应scorer变动是跨配置，不是隔离backbone单因素。source train/tune、首次FineCops确认、V4事后分析的地位分开。

统计部分说明共同图像抽样、重复表达与三个固定seed效应均值；区间不覆盖完整重新训练随机性。V4连续fractional-tie AURC明确版本，旧积分结果保留附录；AUROC不是概率校准，E-AURC也未排除accuracy影响。

## 3. 受控现象：哪些性质变了

主图给Accuracy/AUROC/Risk曲线，先陈述指标之间的关系，再讨论候选组成与困难度。在对应命题旁嵌入类别错配/冗余/敏感性交集审计，不另设十几个“稳健性实验”小节。完整网格放附录。

源域判别退化与FineCops未确认的C1相邻展示，形成一个完整命题的支持与限制；不要先写退化普遍成立，到最后一章才承认不迁移。准确率下降有结构条件，AUROC变化要经验检验。

## 4. 可用信号：训练支持、依赖边界和实际幅度

先看score模型训练支持：大K训练比小K外推改善多少，是否超过MSP/Stats。训练支持效应不能推出分数表示本身缺信息。

接着给S/SQ/SV/Full绝对结果和确认增量，立即说明旧V经query-conditioned winner/rank选锚，不能称纯集合语义贡献。V4用一个冻结12维函数检查更严格的依赖主张，呈现S/SQ/SVpure/Fullpure绝对比较。纯块成功或不确定都放在同一推理位置，不另起“新方法全面胜出”章。

最后解释幅度：真实pair转移有多少恢复/反向损失，净增量按每seed真实pair分母标准化；固定coverage下四个baseline绝对风险和每1000样本减少错误。AURC综合结果与working-point不一致时完整解释，不挑最好coverage。唯一ambiguity分层只用于预定interaction，对边际显著性不能作组间判断。

正文核心表应同时含Accuracy、AUROC、Risk50/80、AURC版本、Δ与调整CI。若Full不是最优，表中明确保留更强简单对照。

## 5. 解释审计：指标变化记在哪里

四角、两切换路径、对称分量与交互项共同展示。图中用有符号贡献，不突出95%/103.9%当作因果解释率。小平均标签项可能来自大反向路径抵消，不能说标签变化不重要。pairwise ranking解释正负组、归一化和置信排序如何共同决定AUROC。

这一章回答统计构成与解释自洽性，不回答模型内部因果机制。依赖隔离也不是因果干预或条件互信息估计；理论的贡献是约束错误解释，而不是创造额外命题数量。

## 6. 外推：首次确认、自然接口与尚未取得的域确认

FineCops首次确认的C2/C3/C4支持与C1不支持分别陈述。自然K5反向、K20漏检错误排序贡献、K50配置/covered边界都作为核心证据；overall增量不冒充定位覆盖后的普遍改善。

V4外部审计若未满足来源/域/权限/可用规模，只能报告未取得该证据，不能画一个“外部实验失败”点。不同图像语料库不自动是明显不同视觉域，项目未用过不等于CLIP预训练未见。若有真正外部确认，紧接相应surviving claim报告正或负迁移，不单独构造新贡献。

## 7. 贡献与停止

最终贡献由证据决定，允许以下有限表达：候选变化的性能性质不能互相替代；训练支持与候选结构相关的预测增量具有具体条件；自然覆盖及域/来源边界限定外推。纯特征若成功，可以强化“给定候选集函数不读取query的结构信号”；若不确定，保留旧query-conditioned块的可用性，不能反推其全部信号的必要来源。

哈希、修补、可复现工具是研究纪律和工程质量，不替代科学贡献。现有一族proposal、固定模型、受控GT条件、训练流程不确定性、预训练暴露与尚未取得外部域证据都明确列出。结束时收束论文，不用架构/数据筛选救回负结果。
